2025年からはフロントエンド・バックエンド・クラウドをまたいだ開発を仕事にしています。得意なのは Node.js・TypeScript・Linux です。

02 / Work

仕事でやってきたこと

02
  1. 1/3公開にかかる時間

    Web サイトの公開作業を自動化

    FTP で手作業していた公開を、S3・CloudFront・GitHub Actions による自動デプロイへ移しました。認証も固定の鍵から OIDC に変えています。

    AWS · GitHub Actions · OIDC

  2. AI営業支援ツール

    営業準備をまとめて支援する社内ツール

    候補の一覧作成から情報確認、入力支援までを一つの流れにしました。要件整理、画面、API、クラウド構成まで担当しています。

    Cloudflare Workers · Queues · D1 · Vue · oRPC

  3. SaaSテナント管理

    AI SaaS とテナント・権限まわり

    組織ごとのデータ分離、管理者と一般ユーザーの権限、外部サービス連携の不具合調査などを担当しました。

    Kotlin · Java · React · AWS · Terraform

  4. 2→3Vue の移行

    Vue 2 から Vue 3 への移行

    TypeScript の更新と合わせて、既存の業務画面を Vue 3 へ移しました。

    Vue · TypeScript
