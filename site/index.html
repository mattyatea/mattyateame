01 / Story

これまでのこと

年齢ごとに振り返ると、だいたいこんな感じです。

  1. 9歳

    はじまりは SmileBASIC

    9歳のころ、SmileBASIC でプログラミングを始めました。

  2. 10歳

    PHP で Web に触れた

    10歳から12歳にかけて、PHP で Web アプリを書いていました。

  3. 13歳

    部屋にサーバーを置いた

    Raspberry Pi 4B 1台で自宅サーバーを始めて、インフラを実際に触るようになりました。Misskey を立てたら、同時接続が60人を超えました。WordPress を公開したり、部屋の照明をサーバーから操作したりもしていました。技術ブログ nanasi-apps.xyz もこの頃に始めています。

  4. 14歳

    自分の SNS をつくった

    Misskey サーバー「まっちゃすきー。」(mattyaski.co) を開設しました。データベースの破損や、ファイルサーバーの消失も経験しています。運営の大変さと面白さは、だいたいここで知りました。Cloudflare Workers も、この頃から今までずっと触っています。

  5. 15歳

    Misskey を自分の手で変えはじめた

    TypeScript と Vue を始めて、Misskey のフォーク「Type4ny」を作り、PrisMisskey.space として運営を始めました。ゲーミングモードのような、ちょっと変わった機能も入れています。同じ年に Misskey 本家の開発にも参加し、Misskey.io の開発にも関わっています。ちゃんとコードを書くようになったのは、ここからです。Azure の VM に Kubernetes のクラスターを組んでみたのも、この頃です。

  6. 16歳

    好きなことが仕事になった

    Fediverse のホスティング事業で、業務委託として働き始めました。Azure と Kubernetes を使ったインフラの構築・運用と、決済まわりの開発を担当していました。

    半年後からは IT 企業で、画面からクラウドまでまとめて作る仕事をしています。Java や Kotlin、PHP の Laravel、React を使い、AWS の S3 と CloudFront での公開も担当しました。

  7. 18歳NOW

    いま

    高校に通いながら、自分のサーバーを2つ運営して、nanasphere では十数台のサーバーの運営を手伝っています。Misskey の開発も続けています。

02 / About me

こんな人です

∞

作るより動かし続けるのが好き

公開したら終わりではなく、更新や障害対応、問い合わせ、バックアップまでが楽しいところだと思っています。自分の SNS を何年も運営してきたので、「そのあと」を先に考えるクセがあります。

↺

失敗は仕組みで直す

バックアップが取れていないことに気付かず、約1年分のデータを失ったことがあります。それからは週1回のバックアップに加えて、2〜3週間ごとに「ちゃんと戻せるか」まで確かめています。

⌘

気になったら、根っこから

表面だけを直すより、仕組みから作り直したくなるタイプです。このサイトも一度ぜんぶ書き直しました。

新しい技術や AI もすぐに試します。ただ、手順が決まっている処理まで AI に任せず、ふつうのコードで書くくらいの冷静さは持っているつもりです。

△

苦手なこともあります

大人数の調整や見積もりは、まだ修行中です。Kubernetes のように、触ってはいても知見がまだ浅い分野もあります。

気になるところを全部拾いにいって抱え込みがちなので、優先順位を一緒に決めてもらえるとすごく助かります。
